## 固定参数真实 BGE 示例结果

BGE `BAAI/bge-small-zh-v1.5` 经 ModelScope 下载至本地。未修改参数反复试保留集。
本次 `top_k=3`、中文占比阈值 `0.3`、BM25 `k1=1.5/b=0.75`，RRF 常数 `60`、权重各 `0.5`。
最终复查改正小语料 IDF 和纯 BM25 平局排序后，为验证缺陷修复重新运行同一示例；
未改查询、标签、权重和阈值，三项指标与首轮一致。当前 IDF 为正值公式
`ln(1 + (N - df + 0.5) / (df + 0.5))`，BM25 同分仅按段落编号排序。

**20 个段落是原创功能样例，相关性标签是预先编写且未经独立人工复核的示例标签。
这不是实际论文检索评测，也不能证明真实效果提升。**

|---|---|---:|---:|---:|

具体案例 `hold08`：纯向量返回段落 `18,15,6`，两个相关标签为 `5,15`，因此 Recall@3=0.5。
含借阅证“核查”词面的干扰段落排在前面。混合模式找回两个相关段落，但本次 MRR 平均值没有改善。
在这份很小的样例上 BM25 与 hybrid 指标相同，不能据此声称融合优于单独 BM25。
